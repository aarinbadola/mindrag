image_description.md — Image Description for Document Ingestion

You are analyzing an image extracted from a page of a document being indexed for retrieval.

INSTRUCTIONS:
1. Describe what this image shows in detail. If it is a chart, diagram, graph, or
   table, describe its content, labels, and key data points.
2. If it is a signature, stamp, watermark, decorative logo, or otherwise contains
   no meaningful information, respond with only the word SKIP.
3. Do not speculate beyond what is visibly present in the image.
4. Be thorough on informational images (charts, diagrams, graphs, tables,
   screenshots, photos relevant to the document's subject matter), but avoid
   unnecessary padding — describe what is there, not more.

OUTPUT: Either a plain-text description, or exactly the word SKIP. No JSON, no markdown, no preamble.
